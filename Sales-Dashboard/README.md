# 📊 Sales Performance Analysis & Forecasting Dashboard

## 🔍 Project Overview
This project presents an interactive **Sales Performance Dashboard** built using Power BI. It transforms raw sales data into meaningful insights to support data-driven decision-making. The dashboard enables users to analyze sales trends, profit distribution, and performance across different regions, categories, and customer segments.

---

## 🎯 Objectives
- To monitor overall sales and profit performance  
- To identify top-performing and underperforming areas  
- To analyze sales trends over time  
- To support business decisions using data visualization  

---

## 📌 Key Features
- 📈 Sales & Profit KPIs (Total Sales, Profit, Quantity, Delivery)
- 🌍 Regional Analysis (West, East, Central, South)
- 💳 Payment Mode Analysis (COD, Online, Cards)
- 📦 Category & Sub-Category Insights
- 🚚 Shipping Mode Analysis
- 👥 Segment Analysis (Consumer, Corporate, Home Office)
- 📅 Time-Based Trends (Monthly & Yearly)
- 🔮 Sales Forecasting & Trend Analysis
- 🗺️ Geographic Visualization of Sales & Profit

---

## 🛠 Tools & Technologies
- **Power BI** – Data Visualization & Dashboard Creation  
- **Excel / CSV** – Data Source  
- **DAX (Data Analysis Expressions)** – Calculations & Measures  

---

## 📊 Dashboard Insights
- Consumer segment contributes the highest sales  
- Standard Class shipping is most preferred  
- Technology category generates the highest profit  
- Sales show seasonal trends with peaks in certain months  
- Certain regions outperform others consistently
